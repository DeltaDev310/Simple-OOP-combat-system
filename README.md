# Simple OOP Combat System

A small C# learning project created to practice the basics of Object-Oriented Programming (OOP).

The project contains a simple combat system where characters can attack each other, take damage, and be defeated.

## Features
- Character classes and objects
- Fields and methods
- Basic turn-based combat
- Health and damage handling
- Simple defeat conditions

## Project Structure
The project mainly consists of a single C# script containing the combat system.

## Purpose
This is a beginner learning project focused on understanding C# and OOP fundamentals. It's intentionally simple and serves as a starting point for more advanced projects.
